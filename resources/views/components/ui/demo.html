Laravel Textarea Component Analysis

Component Explanation

Component Code Breakdown:

@props(['disabled' => false, 'name' => null, 'id' => null, 'placeholder' => null])
@php
  $error = $errors->has($name) ? 'border-red-500 focus:border-red-500 focus:ring-red-200' : '';
@endphp
<textarea name="{{ $name }}" id="{{ $id ?? $name }}" placeholder="{{ $placeholder }}"
  @disabled($disabled)
  {{ $attributes->merge([
    'class' =>
      'mt-1 block w-full rounded-md border bg-white px-3 py-2 text-gray-900 shadow-sm focus:border-blue-500 focus:ring-2 focus:ring-blue-200 outline-none transition resize-y min-h-[120px]',
  ]) }}>{{ old($name, $slot) }}</textarea>
@error('content')
  <small class="text-red-500 text-xs mt-1">{{ $message }}</small>
@enderror

What's happening:

  • @props declares the component's properties with default values
  • $error variable checks if there are validation errors for the field
  • $attributes->merge() allows merging additional classes
  • old($name, $slot) preserves old input on form validation failure
  • @error directive displays validation errors

Usage Example:

<x-ui.textarea
  name="content"
  id="content"
  placeholder="Write your post here..."
  class="additional-classes-here"
>Default content</x-ui.textarea>

Available Props:

Directly Available

  • disabled
  • name
  • id
  • placeholder
  • class (via $attributes)

Not Directly Available

  • rows (but can be passed via attributes)
  • maxlength (but can be passed via attributes)
  • readonly (but can be passed via attributes)

How to Use This Component

Basic Usage:

<x-ui.textarea
  name="content"
  id="content"
  placeholder="Write your post here..."
>Default content</x-ui.textarea>

With Additional Attributes:

<x-ui.textarea
  name="description"
  id="description"
  :disabled="true"
  rows="4"
  maxlength="500"
  class="custom-class"
  placeholder="Enter description..."
>Default description</x-ui.textarea>
